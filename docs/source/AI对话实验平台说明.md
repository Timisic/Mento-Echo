# 研究一 AI 对话实验平台一页说明

> 当前 MVP 实现决策（2026-05-20）：AI 对话为 promptless。以下早期“主题/流程/系统提示语”内容只作为研究设计背景，不得直接作为系统提示词、developer/base instruction 或模型侧话题引导发送给 provider。

## 2. 实验组流程

主题：当前专业是否还要继续读下去，未来升学或就业是否继续走这个方向。

```text
进入实验组入口
→ 确认被试编号
→ 阅读任务说明
→ 开始 AI 对话
→ 围绕专业体验、兴趣困惑、升学就业、自我认识展开讨论
→ AI 在最后 1 到 2 轮做简短整理
→ 跳转后测问卷
→ 完成实验
```

实验组 AI 主要完成：

1. 引导被试描述当前专业体验。
2. 追问关键经历和困惑来源。
3. 帮助被试梳理继续当前方向的理由和犹豫点。
4. 引导被试思考升学、就业和未来生活方式。
5. 最后整理核心困惑、已澄清内容、仍缺信息和下一步验证行动。

最后整理放在对话中完成，不单独生成报告。

## 3. 对照组流程

主题：与身份发展无关的自由话题。

```text
进入对照组入口
→ 确认被试编号
→ 阅读任务说明
→ 开始 AI 对话
→ 围绕电影、音乐、美食、旅游、运动、校园日常等话题聊天
→ AI 做普通结束语
→ 跳转后测问卷
→ 完成实验
```

对照组 AI 需要避免主动讨论：

1. 专业选择。
2. 职业规划。
3. 人生目标。
4. 价值观。
5. 自我认识。
6. 未来发展。

如果被试主动提到这些内容，AI 可以简短回应后拉回轻松话题。

## 4. 分组方式

1. 程序随机分组：被试进入统一入口后，系统随机分到实验组或对照组。
2. 固定入口分组：研究者提前准备实验组入口和对照组入口，被试通过对应链接进入。

预实验可以先用固定入口。正式实验再考虑程序随机分组。两种接口都留着。

## 5. 后台记录内容

后台记录字段建议包括：

1. 被试编号。
2. 组别。
3. 进入平台时间。
4. 对话开始时间。
5. 对话结束时间。
6. 对话总时长。
7. 对话总轮次。
8. 每轮用户输入。
9. 每轮 AI 回复。
10. 是否达到最低轮次。
11. 是否完成对话。
12. 是否跳转后测问卷。
13. 模型名称和版本。
14. prompt mode（当前 MVP 为 promptless，不记录系统提示语版本）。

后续文本分析可基于完整对话记录编码：

1. 用户是否表达专业困惑。
2. 用户是否进行自我反思。
3. 用户是否表达价值观或目标。
4. AI 是否提出开放式问题。
5. AI 是否帮助澄清选择。
6. AI 是否引导形成行动计划。
7. 对照组是否出现身份发展相关内容。

## 6. 确认的点

1. 对话时长和最低轮次是否沿用原方案。【约 20—30 分钟，>=10轮】
