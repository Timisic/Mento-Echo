# Mentor Echo Design Context

## Overview

The UI should be a quiet Chinese research platform. Design serves comprehension, stage control, privacy boundaries, and data-operation trust. Prefer clear structure, restrained color, readable forms, and obvious completion states.

## Colors

Use a restrained product palette: tinted paper backgrounds, navy or blue-gray text, one calm blue primary action, and a muted green success/accent color. Avoid bright gradients, neon, pure black, pure white, and decorative color overload.

## Typography

Use system Chinese-compatible UI fonts unless a deliberate local font strategy is introduced. Prioritize legibility for questionnaire text. Keep body line length comfortable and use weight plus spacing for hierarchy.

## Elevation

Use subtle borders and shallow shadows only when they clarify layered surfaces. Avoid nested cards. Prefer section rhythm and whitespace over repeated card grids.

## Components

- Participant stages should look sequential and guided.
- Questionnaire controls should be large, readable, keyboard accessible, and visibly selected.
- Numeric scales should use clickable scale controls, not dropdowns.
- Categorical options should use visible buttons or cards.
- Dialogue should read as a chat transcript with clear completion progress.
- Admin dashboard should use summary cards, tables, confirmation dialogs, and sensitive export warnings.

## Do's and Don'ts

Do hide all experimental internals from participant screens. Do use neutral Chinese copy. Do make blocked, loading, error, success, locked, and completed states explicit.

Do not use companion-app imagery, therapy language, decorative avatars, side-stripe alert cards, gradient text, excessive rounded cards, or modals as the first answer when inline confirmation is enough.
